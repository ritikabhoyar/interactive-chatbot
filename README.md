# React Chatbot Application

## Overview

The React Chatbot Application is an interactive web-based chatbot built using React.js. It provides users with a simple and engaging chat interface where they can interact with a rule-based virtual assistant. The application demonstrates frontend development concepts such as component-based architecture, state management, event handling, and dynamic UI rendering.

## Features

* Real-time user and bot conversation interface
* Dynamic message rendering using React components
* Rule-based chatbot responses
* Date retrieval functionality
* Coin flip simulation
* Dice roll simulation
* Responsive and user-friendly design
* Interactive chat experience with instant feedback

## Technologies Used

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Vite
* Git & GitHub


## How It Works

1. Users enter a message in the chat input.
2. The chatbot processes the input and checks predefined commands.
3. Based on the command, the bot generates an appropriate response.
4. Responses are displayed dynamically in the chat window.
5. Special commands such as date retrieval, coin flipping, and dice rolling execute corresponding JavaScript logic.

## Key Concepts Implemented

* React Functional Components
* React Hooks (useState)
* Event Handling
* Conditional Rendering
* State Management
* Component Reusability
* Responsive UI Design
* JavaScript Business Logic

## Installation and Setup

### Clone the Repository

```bash
git clone origin https://github.com/ritikabhoyar/interactive-chatbot.git
```

### Navigate to Project Directory

```bash
cd interactive-chatbot
```

### Install Dependencies

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

The application will run locally on:

```text
http://localhost:5173
```
